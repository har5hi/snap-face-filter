## 🎭 Snap with Filters a Real-Time Face Filter Web App
a real-time face filter web application that applies interactive AR-style filters using your webcam. Built with pure HTML, CSS, and JavaScript, it delivers a smooth and visually appealing experience directly in the browser.

---

## 🚀 Features
Real-time webcam face detection
Multiple fun filters (dog ears, flower, hearts, mask, clown, ghost eyes, etc.)
Capture photos with filters applied
View captured images in gallery
Switch between Home, Camera, and Gallery screens
Clean, aesthetic UI with modern design
Fast and lightweight (no heavy frameworks)

---

## 🛠️ Tech Stack
**Frontend:** HTML, CSS, JavaScript
**Face Detection:** Face API / landmark-based positioning
**Styling:** Custom CSS (Glassmorphism + soft UI)

## ⚙️ How to Run Locally

1. Clone the repository:

```
git clone https://github.com/har5hi/snap-face-filter.git
```

2. Open the project folder:

```
cd snap-face-filter
```

3. Run using Live Server OR open `index.html` in browser
